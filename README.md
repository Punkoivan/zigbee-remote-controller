# Zigbee-пульт (XIAO MG24 + клавіатура 4×4)

Пульт на батарейці для Home Assistant (ZHA). Прошивка тільки надсилає номер кнопки, а вся логіка живе в автоматизаціях HA.

Стаття про проєкт: [punka.space](https://punka.space/posts/esp32/remote/)

## Залізо

- Seeed Studio XIAO MG24 (Sense)
- Матрична клавіатура 4×4, 8 пінів
- Li-Po 3.7 В (304045, 500 мА·год) на площадки BAT плати XIAO. Плата сама заряджає батарею від USB-C, тож окремий контролер заряду не потрібен.

| Клавіатура | XIAO | Роль |
|---|---|---|
| 1–4 (рядки R1–R4) | D0–D3 | входи з pull-up, будять чіп |
| 5–8 (колонки C1–C4) | D4–D7 | у спокої тримаються в LOW |

Якщо в клавіатури інший порядок пінів, поправ `ROW_PINS` / `COL_PINS` у `firmware/firmware.ino`.

Номер кнопки: `key = (рядок − 1) × 4 + колонка`, від 1 до 16.

## Прошивка

Основна прошивка — `firmware-sisdk/`, на Silicon Labs Simplicity SDK (2026.6). Пульт працює як **сплячий кінцевий пристрій** Zigbee: радіо вимкнене, чип спить в EM2 і прокидається лише на натискання та рідкісні опитування батька.

`firmware/` — стара версія на Arduino-ядрі Silicon Labs. Бібліотека Zigbee там тримає приймач постійно увімкненим, і 500 мА·год вистачає приблизно на дві доби. Лишена для історії.

### Збірка

Тулчейн ставиться через [Silicon Labs Tool (SLT-CLI)](https://docs.silabs.com/simplicity-installer-slt/latest/slt-cli/install-slt):

```sh
slt install simplicity-sdk slc-cli gcc-arm-none-eabi commander cmake ninja zap
```

Генерація й збірка (шляхи до пакетів показує `slt where <пакет>`):

```sh
cd firmware-sisdk
slc generate -p remote.slcp -d . --with EFR32MG24B220F1536IM48 -o cmake
cd cmake_gcc
cmake --preset project
cmake --build --preset default_config
```

Результат: `cmake_gcc/build/base/remote.hex`. Загрузчика немає, прошивка стартує з `0x08000000`.

`config/` закомічений, бо там вручну задані налаштування XIAO MG24, яких slc сам не знає: піни консолі (USART0, PA8/PA9) у розділі pin tool, потужність при приєднанні. slc не перезаписує наявні файли з `config/`, тож правки там зберігаються. У `config/zcl/zcl_config.zap` шляхи до SDK відносні до моєї машини, їх може знадобитися поправити.

### Прошивка через вбудований CMSIS-DAP (OpenOCD)

```sh
openocd -f interface/cmsis-dap.cfg -f target/efm32s2_g23.cfg \
  -c "init; reset_config srst_nogate; reset halt; program cmake_gcc/build/base/remote.hex verify; reset run; exit"
```

OpenOCD з Arduino-ядра Silicon Labs підходить. Якщо плата зникає з USB посеред прошивки, спробуй інший порт: не кожен USB-порт ноутбука дає достатньо струму.

Щоб забути мережу без натискання кнопок, достатньо стерти NVM3: `flash erase_address 0x08176000 0x8000`.

Перед кожною прошивкою збільшуй `FIRMWARE_VERSION` у `app.c` і значення OTA Current File Version у `.zap`: ZHA показує версію в картці пристрою.

### Що варто знати про плату й чип

- **Клавіатура на порту C не будить чип з EM2.** У EFR32MG24 у сні EM2 будять лише піни портів A і B. Тому рядки клавіатури (PC0–PC3) у спокої перевіряються таймером кожні 50 мс.
- **RF-перемикач антени.** Між чипом і антенами стоїть перемикач (PB5: живлення, PB4: LOW = вбудована антена, HIGH = U.FL). Прошивка вмикає його сама; для зовнішньої антени постав `USE_EXTERNAL_ANTENNA` у `board.c`.
- **Потужність передавача.** Network steering за замовчуванням приєднується з +3 дБм; тут скрізь +10 дБм (максимум для EFR32MG24B220).
- **Зовнішня SPI-флеш** не використовується й переводиться в глибокий сон, щоб не їла батарею.
- **Опитування після приєднання.** Після кожного підключення до мережі пульт 60 с часто опитує батька, щоб ZHA встиг його опитати. Далі він опитує раз на 30 хвилин і після кожного натискання.
- **Rejoin.** Якщо натискання не доставлене або кілька опитувань батька поспіль пропали, штатний модуль SDK шукає нового батька.

## Підключення до ZHA

1. Увімкни в ZHA режим «Add device».
2. Ввімкни пульт. Поки він шукає мережу, світлодіод блимає раз на секунду. Після підключення він блимне тричі.
3. Скидання до заводських: тримай кнопку 1 протягом 5 секунд під час увімкнення чи reset.

Якщо пульт уже був у ZHA з іншою прошивкою, видали його в ZHA перед повторним підключенням. Якщо після кількох спроб ZHA не бачить подій, хоча пульт їх надсилає, перезавантаж інтеграцію ZHA: вона могла лишитися зі старою мережевою адресою пристрою.

## Події в HA

Кожне натискання надходить як `zha_event` з командою `move_to_level`:

- `endpoint_id: 10` — коротке натискання;
- `endpoint_id: 11` — довге натискання (≥ 600 мс);
- `params.level` (те саме, що `args[0]`) — номер кнопки.

```yaml
automation:
  - alias: "Пульт: кнопка 1 — світло у вітальні"
    triggers:
      - trigger: event
        event_type: zha_event
        event_data:
          device_ieee: "xx:xx:xx:xx:xx:xx:xx:xx"
          command: move_to_level
          endpoint_id: 10
    conditions:
      - condition: template
        value_template: "{{ trigger.event.data.params.level == 1 }}"
    actions:
      - action: light.toggle
        target:
          entity_id: light.living_room
```

Заряд батареї (Power Configuration) пульт надсилає після натискань і раз на 30 хвилин. Нижче 3.40 В пульт вимикає радіо й засинає в EM4, розбудити можна кнопкою з першого рядка.

## Корпус

Модель генерується скриптом `case/build_case.py` у FreeCAD (документ `case/remote_case.FCStd`), він же експортує 3MF:

| Файл | Що це |
|---|---|
| `case_tray.3mf` | лоток |
| `case_lid.3mf` | кришка |
| `keycap_row4.3mf` | ряд із 4 ковпачків, друкувати 4 шт. |
| `grid_test.3mf` | тестова пластина для перевірки кроку кнопок |

Лоток побудований за задумом, а кришка й ковпачки підігнані під мій реальний збір (клавіатура й батарея поміняні місцями, положення кнопок виміряні від стінок). Розміри «як зібрано» лежать у блоці `As built` скрипта; для власного збору поміряй і заміни їх.

Запуск без інтерфейсу FreeCAD: відкрий `remote_case.FCStd` і виконай скрипт, наприклад через `freecadcmd`. Скрипт звертається до документа на ім'я `remote_test_plate`.

## Інструменти

`tools/ha_ws.py` — перевірка через WebSocket API Home Assistant (потрібні змінні `HA_URL` і `HA_TOKEN`):

```sh
python tools/ha_ws.py device      # пристрій і його сутності
python tools/ha_ws.py events 60   # zha_event протягом 60 с
```

## Відомі обмеження

- Струм у сні амперметром не міряний. За заряд у HA: на Arduino-прошивці батарея сідала на ~52 % за 21 год, на сплячій прошивці за ~20 год після повної зарядки заряд не змінився в межах похибки (96 → 94–95 %).
- Довге натискання (endpoint 11) на SDK-прошивці ще не перевірене на ділі.
- Затримка натискання до 50 мс через опитування клавіатури таймером.
